Minstrel

Background music that follows the story's mood as you read.

Quick start

  1. Open something to read: a webnovel chapter, fanfiction, any page with real text.
  2. Click the Minstrel icon in the toolbar. A small widget appears at the bottom right.
  3. Read. The music follows the mood of what is on your screen and crossfades when it changes.

The widget has pause, a reading band calibrator, band guides, mute, volume, settings, and close. Click the band button and drag the band to where your eyes usually rest; Minstrel listens to the text inside it.

This works immediately with a built-in keyword classifier. For much smarter mood detection, set up an LLM below. It is free, local, and takes about five minutes.

Smarter moods with a local LLM

Minstrel can ask a small language model running on your own computer to judge each scene. We recommend Ollama, a free app that runs models locally.

ModelDiskRAMVerdict
llama3.2:3b2.0 GB~2 GBRecommended default
qwen2.5:1.5b986 MB~1 GBSmallest that still works well

Windows

  1. Install Ollama from ollama.com/download.
  2. Open PowerShell and run: 
    setx OLLAMA_ORIGINS "chrome-extension://*"
  3. Quit Ollama from the system tray and start it again.
  4. Still in PowerShell: 
    ollama pull llama3.2:3b

Linux

  1. Install Ollama: 
    curl -fsSL https://ollama.com/install.sh | sh
  2. Allow extension origins. If Ollama runs as a systemd service, run sudo systemctl edit ollama and add: 
    [Service]
Environment="OLLAMA_ORIGINS=chrome-extension://*"
    Then sudo systemctl restart ollama. If you run it manually instead: OLLAMA_ORIGINS="chrome-extension://*" ollama serve
  3. ollama pull llama3.2:3b

Connect Minstrel

  1. Click the gear button on the widget to open the settings.
  2. Set LLM endpoint to http://localhost:11434/v1
  3. Set Model to llama3.2:3b and leave the API key empty.
  4. Click Save.
Chrome will ask for permission when you save. Minstrel needs your OK to talk to the endpoint address you just entered, and nothing else. If you deny it, the LLM cannot be reached and Minstrel quietly falls back to the keyword classifier.

Tip: paste a one paragraph synopsis of your current book in the settings. The model uses it to match the music to the story's overall tone.

Hosted APIs instead

Any OpenAI compatible service works: set its endpoint (for example https://openrouter.ai/api/v1), your API key, and a model name. Minstrel sends roughly one small request per screenful of text, so the cost is negligible. The same permission prompt applies.

Privacy

Minstrel collects nothing and has no servers. By default nothing leaves your browser. With an LLM configured, the visible passage is sent only to the endpoint you chose. Details: privacy policy.
